# Documentation Assets

This folder contains screenshots and documentation assets for the README.

## Required Screenshots

To complete the README documentation, add the following screenshots:

1. `dashboard.png` - Screenshot of the main dashboard
2. `users.png` - Screenshot of user management page
3. `register-face.png` - Screenshot of face registration page
4. `recognize.png` - Screenshot of face recognition page
5. `attendance.png` - Screenshot of attendance records page

## How to Capture Screenshots

1. Open the application at https://facial-recognition-project-six.vercel.app
2. Navigate to each page
3. Use browser screenshot tools or Snipping Tool (Windows)
4. Save with the appropriate filename
5. Commit and push to update the README

## Optional Assets

- `logo.png` - Project logo for branding
- `architecture.png` - System architecture diagram
- `demo.gif` - Animated demo of the application
